# Voice Assistant 🤖

This is a Python-based voice assistant.

## 🔥 Features
- Voice recognition
- Open Google, YouTube, etc.
- Tells time and battery status
- Wikipedia search

## 💻 Tech Used
- Python
- SpeechRecognition
- pyttsx3
- pyautogui

## ▶️ Run
pip install pyttsx3 SpeechRecognition wikipedia pyautogui psutil pyaudio  
py -3.10 voice_assistant.py
